# 5편. 모델 중간 층을 직접 학습시키기

> 4편에서는 마지막 층 하나만 고칠 수 있었고, 그러면 배우는 만큼 잊어버렸다. 이번엔 한 발 더 들어가서 모델 중간 층의 가중치를 8GB 안에서 학습하는 길을 뚫어 봤다.

2026-11-23 · RTX 3070 8GB / RAM 16GB · Qwen3.6-35B-A3B (IQ3_S)

## 결론부터

| 주제 | 결과 |
|---|---|
| 중간 층(12 - 39층, 28개 층) 가중치 학습 | **된다.** 8GB GPU에서 실제 35B 모델의 28개 층을 정확한 역전파로 학습했고, 원래 채팅 엔진(llama.cpp)에 LoRA로 얹어서 확인했다 |
| 처음 보는 표현의 질문에 정답 (실제 엔진) | 4편 1.9% → s1 5.3% → 자기 문제 연습 7.8% → 갱신 1회 **24.3%** → 갱신 2회 **36.9%** |
| 무관한 글에서 원래 답 유지 (실제 엔진) | 67.7% → 80.5% → 83.9% → 81.5% → 80.3% |
| 한국 시험 문제 | 검색 지식으로 공개 데이터셋 **25만 3천 문항**을 넣었다 (평가용 시험은 제외) |
| 한국어 사전·신조어 | 위키낱말사전 82,476표제어(속어·은어 표시 537개) |

배우는 양은 크게 늘었다. 하지만 무관한 글을 80% 정도만 지키는 건 아직 너무 많이 흔들리는 거라, 이 사실 학습 LoRA는 채팅 앱에 넣지 않았다.

## 지난번 방법(직접 경로)은 왜 실패했나

4편 끝에 처음 시도한 건, 각 층의 출력을 바꿨을 때 최종 답이 어떻게 변할지 **근사**해서(DFA식: 위층을 건너뛰고 최종 오차를 바로 보내기) 학습하는 방법이었다.

| | 학습 중 예측 | 실제 엔진 |
|---|---|---|
| 새 질문 정답 | 10% | **1.9%** |
| 학습 문장 토큰 | 81% | 44% |
| 무관한 글 유지 | 80% | 68% |

위층들(어텐션, Gated DeltaNet)이 바뀐 신호를 다시 섞어 버리니까 근사가 실제와 크게 어긋났다. 근사를 다시 맞추며 반복할수록 더 나빠져서(학습 문장 32%, 무관한 글 41%) 접었다.

## 해결: "전문가는 고정, 나머지는 정확히" 대리 모델

35B 모델은 8GB GPU에 다 안 올라간다. 그런데 무거운 건 256개 **라우팅 전문가**다. 그래서 이렇게 나눴다.

1. llama.cpp를 평소처럼 돌리면서 각 층의 라우팅 전문가 **출력**만 꺼내 저장한다(`hm_host.exe`).
2. 나머지는 전부 PyTorch로 다시 짰다(`qwen_torch.py`). 28개 층의 어텐션, Gated DeltaNet(선형 어텐션), 정규화, 공유 전문가. 3비트 가중치를 그대로 풀어서 쓰고, 층마다 체크포인트를 둬서 GPU는 **1.9GB**만 쓴다.
3. 이 대리 모델 위에서 공유 전문가의 LoRA를 **정확한 역전파**로 학습한다.
4. llama.cpp LoRA로 내보내서 **원래 엔진**으로 채점한다.

**검증:** 대리 모델과 실제 엔진의 최종 출력 차이는 약 1%, 다음 토큰 일치율은 99.8 - 100%였다. 여기까지 맞추는 게 꽤 까다로웠다. q/k 헤드 복제 방식이 "tile"이어야 했고, q에 1/√128 배율을 걸어야 했다. 다른 조합은 선형 어텐션 오차가 컸다.

## 사람처럼 공부하기 ①: 스스로 문제 내고 풀기 (인출 연습)

학습 문장만 외우면 같은 문장은 잘 맞히는데 **다른 표현의 질문**에는 약했다. 사람도 교과서를 반복해 읽기보다 스스로 문제를 내서 풀 때 더 잘 기억한다(시험 효과).

- 모델에게 학습 문장만 보여 주고 사실마다 질문 6개를 만들게 했다. 1,701개를 남기고 1,198개는 버렸다(답에 정답 단어가 없거나 평가 질문과 똑같은 경우).
- 평가 질문은 모델에게 **한 번도 보여 주지 않았다.**

| (대리 모델 기준) | 자기 문제 없이 | 자기 문제 연습 |
|---|---|---|
| 새 질문 정답 | 6.6% | **14.8%** |
| 첫 토큰 정답 | 31.9% | 40.3% |
| 무관한 글 유지 | 90.8% | 90.8% |

**혹시 답을 훔쳐본 건 아닐까?** 모델이 우연히 평가 질문과 비슷한 문제를 만들었을 수도 있다. 그래서 평가 질문을 "가장 비슷한 자기 문제와의 유사도"로 나눠 따로 채점했다.

| 가장 비슷한 자기 문제와의 유사도 | 문항 수 | 정답 |
|---|---|---|
| 0.5 미만 (확실히 다름) | 911 | 14.9% |
| 0.5 - 0.7 | 114 | 15.8% |
| 0.7 이상 (거의 같음) | 55 | 10.9% |

전혀 다른 표현의 질문에서도 향상이 그대로였다. 누출 때문이 아니다.

## 사람처럼 공부하기 ②: 배운 상태로 다시 점검하기 (갱신 라운드)

대리 모델은 전문가 출력을 **고정**한다. 그런데 학습으로 신호가 바뀌면 실제 엔진에서는 라우팅과 전문가 출력도 같이 바뀐다. 그래서 대리 모델 예측(14.8%)과 실제(7.8%)가 벌어졌다.

- 해결: 학습한 LoRA를 **실제 엔진에 얹은 채로** 전문가 출력을 다시 꺼내고, 그 위에서 이어서 학습한다.
- 확인: 다시 꺼낸 직후 대리 모델 점수(7.9%, 유지 84.8%)가 실제 엔진(7.8%, 83.9%)과 거의 같았다. 원인이 정확히 이거였다.

| 실제 엔진 결과 | 새 질문 정답 | 첫 토큰 | 학습 문장 토큰 | 무관한 글 유지 |
|---|---|---|---|---|
| 원래 모델 | 0% | 12% | 28% | 100% |
| 4편 직접 경로 | 1.9% | 28.3% | 43.7% | 67.7% |
| s1 대리 모델 | 5.3% | 30.4% | 66.2% | 80.5% |
| r1 + 자기 문제 | 7.8% | 33.3% | 65.9% | 83.9% |
| r1b + 갱신 1회 | 24.3% | 53.9% | 77.7% | 81.5% |
| **r1c + 갱신 2회, 재생 강화** | **36.9%** | **65.2%** | 80.6% | 80.3% |
| (참고) 3편 해마 기억, 한 번 쓰기 | 33.6% | – | – | 98.6% |

갱신 라운드 두 번으로 실제 엔진에서 처음으로 3편의 해마 기억을 넘어섰다(36.9% 대 33.6%). 진짜 가중치에 사실이 들어간 거다. 대신 무관한 글 유지는 80%대에서 더 오르지 않았다. 가중치에 많이 넣을수록 흔들린다는 4편의 줄다리기가 층을 넓혀도 사라지진 않았다. 이 경험 때문에 6편에서는 망각 방지를 훨씬 세게 걸고, "92% 이상 유지"를 통과 조건으로 못 박았다.

## 한국어 지식은 검색으로 넣었다

"더 가르치기"를 두 갈래로 나눴다.
- **사실·문제·해설처럼 양이 많은 지식**은 가중치에 넣으면 지금 기술로는 망각이 크다(위 표의 "무관한 글 유지"). 그래서 채팅 앱이 질문마다 찾아 쓰는 검색 지식으로 넣었다.
- **가중치 학습**은 위 실험처럼 적은 양을 깊게 정착시키는 데 쓴다.

| 저장소 | 내용 | 크기 |
|---|---|---|
| 시험 문제 (`study.db`) | 공무원 시험 11,301 + 해설 5,060, KMMLU 206,512(학습·개발용만), KMMLU-Pro 6,214, KorMedMCQA 7,488, CSAT-QA 1,123, HRM8K 8,011, 한국어 실생활 질문 7,768 | 220MB |
| 사전 (`dict.db`) | 위키낱말사전 82,476표제어, 그중 속어·은어·비표준어 537개 표시 | – |

- 공정하게 재려고 평가용 시험(HAE-RAE, KMMLU 시험용, 공무원 평가용, 2025 수능)은 넣지 않았고, 겹치는 문항 4,948개도 뺐다.
- 사전 뜻은 "~ 뜻이 뭐야?"처럼 뜻을 묻거나 속어일 때만 붙인다. 안 그러면 "무슨", "치아" 같은 흔한 단어 뜻이 답을 흐렸다.

## 지킨 원칙
- 시스템에 새로 설치한 건 없다. 전부 작업 폴더 안에 있다.
- 학습은 GPU 약 2GB로, 채팅 엔진을 끈 상태에서만 돌렸다. 끝난 뒤 엔진 프로세스가 남지 않았는지 확인했다.
- 서버는 전부 127.0.0.1에서만 열린다.

## 재현
- 전문가 출력 추출: `scripts/hm/extract_surr.py` (환경변수 `CACHE`, `SURR`, `TAG`, `LORA`)
- 대리 모델: `scripts/hm/qwen_torch.py`, 검증 `valid_torch.py`, `valid_stack.py`
- 학습·내보내기: `scripts/hm/train_surr.py --edit 12-39 --rank 16 --wd_bg 3 --export out.gguf --dump items.json`
- 자기 문제 만들기: `scripts/hm/gen_rehearsal.py` (`run_rehearsal.sh`)
- 갱신 라운드: `scripts/hm/refresh.sh 이전 다음 재생강도 에폭`
- 실제 엔진 채점: `scripts/hm/eval_mid.py adapter.gguf` → `results/mid_real.jsonl`
- 지식 저장소: `scripts/kb/build_study.py`, `build_dict.py`
